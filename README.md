## Keyboard Shortcuts

Shortcuts are disabled while typing in the search box.

### Playback Controls

| Shortcut  | Action                        |
| --------- | ----------------------------- |
| `Space`   | Play / Pause                  |
| `←`       | Seek backward                 |
| `→`       | Seek forward                  |
| `0` – `9` | Seek to 0% – 90% of the track |

### Audio Controls

| Shortcut    | Action                          |
| ----------- | ------------------------------- |
| `M`         | Mute / Unmute                   |
| `↑`         | Increase playback volume by 5%  |
| `↓`         | Decrease playback volume by 5%  |
| `Shift + ↑` | Increase input volume by 5%     |
| `Shift + ↓` | Decrease input volume by 5%     |
| `C`         | Toggle Crossfeed                |
| `E`         | Open Equalizer                  |
| `S`         | Open Sleep Timer                |
| `L`         | Like / Unlike the current track |

### Navigation

| Shortcut    | Action            |
| ----------- | ----------------- |
| `Shift + Q` | Open Queue        |
| `Shift + L` | Open Liked Tracks |
| `Shift + R` | Open Radio        |
| `Shift + T` | Open Tracks       |
| `Shift + E` | Open Explorer     |
| `Shift + D` | Open Downloads    |

### Window Controls

| Shortcut | Action           |
| -------- | ---------------- |
| `F`      | Enter fullscreen |
| `Esc`    | Exit fullscreen  |

### Search

| Shortcut   | Action                        |
| ---------- | ----------------------------- |
| `Ctrl + K` | Focus the search bar          |
| `Ctrl + F` | Focus the search bar          |
| `⌘ + K`    | Focus the search bar on macOS |
| `⌘ + F`    | Focus the search bar on macOS |
